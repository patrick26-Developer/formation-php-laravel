# Level 04 — Databases in Depth

> **Status:** ✅ Available · Tier: Cross-cutting

You already know how to use MySQL with PDO (level 02). This level goes deeper into the **design** and **optimization** of relational databases — cross-cutting skills that apply just as much to native PHP as to Laravel/Eloquent.

## Prerequisites

[Level 02 — Intermediate PHP](../02-php-intermediaire/README.en.md) (notably module 02.8 — PDO and MySQL).

## By the end of this level, you will be able to

- Design a relational data model before writing a single line of code.
- Write complex joins, manage transactions, and understand integrity constraints.
- Analyze and optimize a slow query with `EXPLAIN` and well-chosen indexes.
