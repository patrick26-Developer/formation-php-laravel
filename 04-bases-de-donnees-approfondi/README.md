# Niveau 04 — Bases de données approfondies

> **Statut :** ✅ Disponible · Palier : Transversal

Vous savez déjà utiliser MySQL avec PDO (niveau 02). Ce niveau approfondit la **conception** et l'**optimisation** des bases de données relationnelles — des compétences transversales qui s'appliquent aussi bien au PHP natif qu'à Laravel/Eloquent.

## Prérequis

[Niveau 02 — PHP Intermédiaire](../02-php-intermediaire/README.md) (notamment le module 02.8 — PDO et MySQL).

## À la fin de ce niveau, vous saurez

- Concevoir un modèle de données relationnel avant d'écrire la moindre ligne de code.
- Écrire des jointures complexes, gérer des transactions, et comprendre les contraintes d'intégrité.
- Analyser et optimiser une requête lente avec `EXPLAIN` et des index bien choisis.
