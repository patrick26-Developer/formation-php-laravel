# Niveau 00 — Introduction & mise en place

> **Statut :** ✅ Disponible · Palier : Pré-requis

Avant d'écrire la moindre ligne de PHP, ce niveau pose les fondations : comprendre comment est construit ce parcours, installer un environnement de travail fonctionnel, savoir utiliser Git/GitHub au quotidien, et adopter une méthode d'apprentissage qui tient sur la durée.

## Modules

| # | Module | Ce que vous y gagnez |
|---|---|---|
| [00.1](01-presentation-parcours/README.md) | Présentation du parcours | Comprendre la logique des 15 niveaux et comment progresser efficacement |
| [00.2](02-installation-environnement/README.md) | Installation de l'environnement | PHP, Composer, un éditeur, un serveur local — un environnement qui fonctionne |
| [00.3](03-git-github-essentiels/README.md) | Git & GitHub essentiels | Versionner son code et suivre sa progression comme un développeur professionnel |
| [00.4](04-methodologie-apprentissage/README.md) | Méthodologie d'apprentissage | Comment lire un module, pratiquer, et ne pas retomber dans le "tutorial hell" |

## À la fin de ce niveau, vous saurez

- Expliquer la structure de la formation et savoir où trouver quoi.
- Avoir PHP, Composer et un éditeur de code fonctionnels sur votre machine.
- Créer un dépôt Git, committer, pousser sur GitHub.
- Suivre une méthode de travail qui alterne théorie courte / pratique immédiate.
