# Level 00 — Introduction & Setup

> **Status:** ✅ Available · Tier: Prerequisite

Before writing a single line of PHP, this level lays the foundation: understanding how this path is built, setting up a working development environment, knowing how to use Git/GitHub day to day, and adopting a learning method that holds up over time.

## Modules

| # | Module | What you gain from it |
|---|---|---|
| [00.1](01-presentation-parcours/README.en.md) | Path overview | Understand the logic of the 15 levels and how to progress efficiently |
| [00.2](02-installation-environnement/README.en.md) | Environment setup | PHP, Composer, an editor, a local server — a working environment |
| [00.3](03-git-github-essentiels/README.en.md) | Git & GitHub essentials | Version your code and track your progress like a professional developer |
| [00.4](04-methodologie-apprentissage/README.en.md) | Learning methodology | How to read a module, practice, and avoid falling into "tutorial hell" |

## By the end of this level, you will be able to

- Explain the structure of the training and know where to find what.
- Have PHP, Composer, and a code editor working on your machine.
- Create a Git repository, commit, and push to GitHub.
- Follow a work method that alternates short theory with immediate practice.
