# Exercises — 14.3 Technical Interview Preparation

## Exercise 1 — Answering with a concrete example (easy)

For three of the knowledge questions listed in the lesson, write a 3-4 sentence answer illustrated with an example drawn from a specific project in this training (name the file/module).

## Exercise 2 — STAR method (easy)

Choose a technical difficulty you actually ran into while going through this training (a failing test, an N+1 bug you discovered, a configuration mistake). Write a complete answer in STAR format.

## Exercise 3 — Preparing a portfolio presentation (medium)

Write the complete script (3-5 minutes, spoken) for presenting ONE of the three level 13 large projects, following the lesson's structure (problem, technical choices, difficulty, critical hindsight). Base it on the chosen project's `JOURNAL.md`.

## Exercise 4 — Algorithm exercise with no framework (medium)

In plain PHP (no Laravel), write a function `motsLesPlusFrequents(string $texte, int $n): array` returning the `$n` most frequent words in a text, sorted by descending frequency. Discuss your solution's complexity (hint: `array_count_values()` can help, but explain why/why not to use it).

## Exercise 5 — Simulating a system design interview (hard)

An interviewer asks: *"How would you design a notification system able to handle 10 million users?"* First write a list of 5 clarifying questions you'd ask BEFORE answering (scope, constraints, channels). Then sketch an answer, explicitly drawing on concepts already covered in this training (queues, cache, multi-channel notifications, rate limiting).
