# Niveau 11 — DevOps : Docker & CI/CD avancés

> **Statut :** ✅ Disponible · Palier : Expert

Vous avez découvert Docker et un premier pipeline CI au [niveau 05](../05-outils-professionnels/README.md), sur des scripts PHP simples. Ce niveau applique ces mêmes outils à une **vraie application Laravel complète** (celles construites aux niveaux 06 à 10) : image de production optimisée, environnements multiples, pipeline complet (tests, analyse statique, build, déploiement), et supervision en production.

## Prérequis

[Niveau 10 — Fullstack avec Livewire](../10-fullstack-laravel-livewire/README.md), [Niveau 05 — Outils professionnels](../05-outils-professionnels/README.md)

## À la fin de ce niveau, vous saurez

- Construire une image Docker de production pour une application Laravel complète.
- Gérer proprement plusieurs environnements (développement, staging, production).
- Automatiser tests, analyse statique et déploiement via un pipeline CI/CD complet.
- Déployer une application Laravel sur un serveur réel.
- Surveiller une application en production et diagnostiquer un incident via les logs.
