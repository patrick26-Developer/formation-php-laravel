# Level 11 — DevOps: Advanced Docker & CI/CD

> **Status:** ✅ Available · Tier: Expert

You discovered Docker and a first CI pipeline in [level 05](../05-outils-professionnels/README.en.md), on simple PHP scripts. This level applies those same tools to a **complete, real Laravel application** (the ones built in levels 06 through 10): an optimized production image, multiple environments, a full pipeline (tests, static analysis, build, deployment), and production monitoring.

## Prerequisites

[Level 10 — Fullstack with Livewire](../10-fullstack-laravel-livewire/README.en.md), [Level 05 — Professional Tools](../05-outils-professionnels/README.en.md)

## By the end of this level, you will be able to

- Build a production Docker image for a complete Laravel application.
- Cleanly manage several environments (development, staging, production).
- Automate tests, static analysis, and deployment via a complete CI/CD pipeline.
- Deploy a Laravel application to a real server.
- Monitor an application in production and diagnose an incident via logs.
