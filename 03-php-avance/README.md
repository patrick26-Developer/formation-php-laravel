# Niveau 03 — PHP Avancé

> **Statut :** ✅ Disponible · Palier : Intermédiaire → Avancé

Ce niveau clôt la partie "PHP sans framework" de la formation. Vous allez apprendre à structurer du code à grande échelle avec les design patterns, construire votre propre mini-framework MVC, tester votre code automatiquement, et construire une API REST en PHP natif. C'est le niveau qui vous donnera les clés pour comprendre **pourquoi** Laravel est conçu comme il l'est.

## Prérequis

[Niveau 02 — PHP Intermédiaire](../02-php-intermediaire/README.md) complété.

## À la fin de ce niveau, vous saurez

- Reconnaître et implémenter les design patterns les plus courants en PHP.
- Construire un routeur et une architecture MVC de zéro.
- Écrire des tests automatisés pour vérifier que votre code fonctionne, sans le tester manuellement à chaque fois.
- Construire une API REST en PHP natif, sans framework.
- Écrire du code conforme aux standards professionnels (PSR-12, SOLID).
