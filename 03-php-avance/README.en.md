# Level 03 — Advanced PHP

> **Status:** ✅ Available · Tier: Intermediate → Advanced

This level closes out the "PHP without a framework" part of the training. You'll learn to structure code at scale with design patterns, build your own mini MVC framework, test your code automatically, and build a REST API in native PHP. This is the level that gives you the keys to understanding **why** Laravel is designed the way it is.

## Prerequisites

[Level 02 — Intermediate PHP](../02-php-intermediaire/README.en.md) completed.

## By the end of this level, you will be able to

- Recognize and implement the most common design patterns in PHP.
- Build a router and an MVC architecture from scratch.
- Write automated tests to verify your code works, without manually testing it every time.
- Build a REST API in native PHP, without a framework.
- Write code that follows professional standards (PSR-12, SOLID).
