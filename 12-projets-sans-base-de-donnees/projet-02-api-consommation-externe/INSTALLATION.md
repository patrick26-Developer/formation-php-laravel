# Installation

## Prérequis

- PHP 8.3+, Composer.
- Une connexion internet (pour l'appel réel à l'API météo ; les tests, eux, n'en ont pas besoin — voir [JOURNAL.md](JOURNAL.md)).

## Étapes

```bash
composer install
```

## Vérification

```bash
composer test
```

Passez à [EXECUTION.md](EXECUTION.md).
