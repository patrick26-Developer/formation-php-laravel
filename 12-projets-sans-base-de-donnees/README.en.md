# Level 12 — Projects Without a Database

> **Status:** ✅ Available · Tier: Cross-cutting practice

Every previous project relied on a database. This level shows that PHP and Laravel remain just as relevant for needs that don't require one: file generation, consuming external APIs, command-line tools.
