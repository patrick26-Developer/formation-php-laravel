# Niveau 12 — Projets sans base de données

> **Statut :** ✅ Disponible · Palier : Pratique transversale

Tous les projets précédents reposaient sur une base de données. Ce niveau montre que PHP et Laravel restent tout aussi pertinents pour des besoins qui n'en nécessitent pas : génération de fichiers, consommation d'API externes, outils en ligne de commande.

## Projets

| Projet | Statut |
|---|---|
| [Générateur de PDF en ligne de commande](projet-01-generateur-pdf-cli/README.md) | ✅ |
| [Consommation d'une API externe](projet-02-api-consommation-externe/README.md) | ✅ |
| [Outil CLI avec Artisan](projet-03-outil-ligne-de-commande-artisan/README.md) | ✅ |

## Prérequis

[Niveau 11 — DevOps avancé](../11-devops-docker-cicd-avance/README.md), [01.8 — Fichiers, includes et organisation](../01-php-fondamentaux/08-fichiers-et-includes/README.md)

## À la fin de ce niveau, vous saurez

- Générer des fichiers PDF depuis PHP en ligne de commande.
- Consommer une API HTTP externe avec mise en cache locale, sans base de données.
- Créer vos propres commandes Artisan personnalisées.
