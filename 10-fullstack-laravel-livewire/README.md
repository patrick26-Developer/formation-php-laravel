# Niveau 10 — Fullstack avec Livewire

> **Statut :** ✅ Disponible · Palier : Expert Fullstack

Une API séparée (niveau 09) n'est pas toujours nécessaire : **Livewire** permet de construire des interfaces réactives (recherche en temps réel, formulaires dynamiques, mises à jour sans rechargement de page) en restant **100% en PHP**, sans écrire de JavaScript ni maintenir une API distincte.

## Prérequis

[Niveau 09 — API REST avec Laravel](../09-api-rest-laravel/README.md), [06.3 — Blade](../06-laravel-fondamentaux/03-blade-templates/README.md)

## À la fin de ce niveau, vous saurez

- Créer des composants Livewire réactifs sans écrire de JavaScript.
- Construire des formulaires validés en temps réel.
- Ajouter de l'interactivité légère côté client avec Alpine.js en complément.
- Construire des tables de données dynamiques (tri, filtre, recherche) sans rechargement de page.
