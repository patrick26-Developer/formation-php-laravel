# Niveau 09 — API REST avec Laravel

> **Statut :** ✅ Disponible · Palier : Expert Backend

Vous avez construit une API REST en PHP natif au [module 03.4](../03-php-avance/04-construction-api-rest-php-natif/README.md). Ce niveau montre comment Laravel industrialise chaque aspect de cette construction : structuration des réponses, authentification par jeton, documentation, sécurité — pour livrer une API prête à consommer par une application mobile ou un frontend JavaScript découplé.

## Prérequis

[Niveau 08 — Laravel Avancé](../08-laravel-avance/README.md), [03.4 — Construction d'une API REST en PHP natif](../03-php-avance/04-construction-api-rest-php-natif/README.md)

## À la fin de ce niveau, vous saurez

- Concevoir une API RESTful cohérente et prévisible.
- Structurer des réponses JSON avec les API Resources.
- Authentifier des clients API (SPA, mobile, machine-à-machine) avec Sanctum ou Passport selon le besoin.
- Documenter une API avec OpenAPI/Swagger.
- Protéger une API contre les abus avec le rate limiting.
