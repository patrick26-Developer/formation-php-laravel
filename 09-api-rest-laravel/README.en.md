# Level 09 — REST API with Laravel

> **Status:** ✅ Available · Tier: Expert Backend

You built a REST API in native PHP in [module 03.4](../03-php-avance/04-construction-api-rest-php-natif/README.en.md). This level shows how Laravel industrializes every aspect of that build: response structuring, token authentication, documentation, security — to ship an API ready to be consumed by a mobile app or a decoupled JavaScript frontend.

## Prerequisites

[Level 08 — Advanced Laravel](../08-laravel-avance/README.en.md), [03.4 — Building a REST API in Native PHP](../03-php-avance/04-construction-api-rest-php-natif/README.en.md)

## By the end of this level, you will be able to

- Design a consistent, predictable RESTful API.
- Structure JSON responses with API Resources.
- Authenticate API clients (SPA, mobile, machine-to-machine) with Sanctum or Passport depending on the need.
- Document an API with OpenAPI/Swagger.
- Protect an API against abuse with rate limiting.
