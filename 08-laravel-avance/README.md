## À la fin de ce niveau, vous saurez

- Traiter des tâches lourdes en arrière-plan sans ralentir la réponse HTTP.
- Découpler votre code avec des événements et écouteurs.
- Mettre en cache des données coûteuses à calculer.
- Écrire des tests modernes avec Pest.
- Structurer une application Laravel qui grandit sans devenir ingérable.
