# Level 02 — Intermediate PHP

> **Status:** ✅ Available · Tier: Beginner → Intermediate

This level marks a turning point: you leave purely procedural PHP behind to enter **object-oriented programming (OOP)**, essential for understanding Laravel later. You'll also learn to secure your applications, connect to a real database, and build a complete CRUD.

## Prerequisites

[Level 01 — PHP Fundamentals](../01-php-fondamentaux/README.en.md) completed.

## By the end of this level, you will be able to

- Design classes and make them interact through inheritance and interfaces.
- Secure an application against the most common web vulnerabilities.
- Install dependencies with Composer and organize your code according to PSR standards.
- Connect to MySQL with PDO and build a full CRUD (create/read/update/delete) with sorting, filtering, and search.
