# Niveau 02 — PHP Intermédiaire

> **Statut :** ✅ Disponible · Palier : Débutant → Intermédiaire

Ce niveau marque un tournant : vous quittez le PHP purement procédural pour entrer dans la **programmation orientée objet (POO)**, indispensable pour comprendre Laravel plus tard. Vous apprendrez aussi à sécuriser vos applications, à vous connecter à une vraie base de données, et à construire un CRUD complet.

## Prérequis

[Niveau 01 — PHP Fondamentaux](../01-php-fondamentaux/README.md) complété.

## À la fin de ce niveau, vous saurez

- Concevoir des classes, les faire interagir par héritage et interfaces.
- Sécuriser une application contre les failles web les plus courantes.
- Installer des dépendances avec Composer et organiser son code selon les standards PSR.
- Vous connecter à MySQL avec PDO et construire un CRUD complet (créer/lire/modifier/supprimer) avec tri, filtres et recherche.
