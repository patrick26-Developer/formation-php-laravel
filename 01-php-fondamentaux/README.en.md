# Level 01 — PHP Fundamentals

> **Status:** ✅ Available · Tier: Beginner

[Level 00 — Introduction](../00-introduction/README.en.md) completed (environment installed).

## By the end of this level, you will be able to

- Write PHP scripts using variables, conditionals, loops, and functions.
- Work with arrays and strings.
- Process data sent by an HTML form.
- Organize a small PHP project across multiple files.
