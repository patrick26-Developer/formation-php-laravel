# Niveau 01 — PHP Fondamentaux

> **Statut :** ✅ Disponible · Palier : Débutant

## Prérequis

[Niveau 00 — Introduction](../00-introduction/README.md) complété (environnement installé).

## À la fin de ce niveau, vous saurez

- Écrire des scripts PHP utilisant variables, conditions, boucles et fonctions.
- Manipuler des tableaux et des chaînes de caractères.
- Traiter les données envoyées par un formulaire HTML.
- Organiser un petit projet PHP en plusieurs fichiers.
