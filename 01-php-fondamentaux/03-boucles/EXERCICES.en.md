# Exercises — 01.3 Loops

## Exercise 1 — Multiplication table (easy)

With a `for` loop, print the multiplication table of 7, from 7×1 to 7×10.

## Exercise 2 — Sum and average (easy)

With an array `$notes = [12, 15, 8, 17, 10];`, use `foreach` to calculate the sum then the average of the grades, without using `array_sum()`.

## Exercise 3 — FizzBuzz (medium)

The programming classic: from 1 to 30, print "Fizz" if the number is divisible by 3, "Buzz" if divisible by 5, "FizzBuzz" if divisible by both, otherwise the number itself.

## Exercise 4 — Prime numbers (medium)

Print all prime numbers between 2 and 50, using nested loops and `break`/`continue` to optimize (stop as soon as a divisor is found).

## Exercise 5 — Star triangle (hard)

With nested loops, print this pattern for a height of 5:

```
*
**
***
****
*****
```

Then modify your code so it works with any height passed in a `$hauteur` variable.
