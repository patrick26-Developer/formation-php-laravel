## Prérequis

[Niveau 06 — Laravel Fondamentaux](../06-laravel-fondamentaux/README.md) complété.

## À la fin de ce niveau, vous saurez

- Modéliser des relations complexes (many-to-many, polymorphiques) avec Eloquent.
- Encapsuler la logique métier dans les modèles avec scopes, accessors, mutators.
- Sécuriser une application avec une authentification complète et un système d'autorisations fin.
- Gérer l'upload de fichiers et l'envoi d'emails/notifications.
