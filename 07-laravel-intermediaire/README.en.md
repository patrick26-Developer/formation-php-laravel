## Prerequisites

[Level 06 — Laravel Fundamentals](../06-laravel-fondamentaux/README.en.md) completed.

## By the end of this level, you will be able to

- Model complex relationships (many-to-many, polymorphic) with Eloquent.
- Encapsulate business logic in models with scopes, accessors, mutators.
- Secure an application with complete authentication and a fine-grained authorization system.
- Handle file uploads and send emails/notifications.
