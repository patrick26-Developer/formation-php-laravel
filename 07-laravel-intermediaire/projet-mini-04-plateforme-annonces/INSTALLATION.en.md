# Installation

## Prerequisites

- PHP 8.3+, Composer, Node.js/npm (for Breeze assets), MySQL/MariaDB.
- Having completed modules 07.1 through 07.7.

## Steps

### 1. Create the project and install Breeze

```bash
composer create-project laravel/laravel plateforme-annonces
cd plateforme-annonces
composer require laravel/breeze --dev
php artisan breeze:install blade
npm install && npm run build
```

### 2. Add the relationships to the User model

Open `app/Models/User.php` (generated by Breeze) and add the contents of
`app/Models/User-additions.php` provided here (the `annonces()` and `favoris()` methods).

### 3. Copy this mini-project's files

Copy `database/`, `app/Models/Category.php`, `app/Models/Annonce.php`,
`app/Models/Message.php`, `app/Policies/`, `app/Notifications/`,
`app/Http/Controllers/`, `app/Http/Requests/`, `routes/web.php` (merge
with Breeze's: keep its `require __DIR__.'/auth.php'`), and
`resources/views/` into the project.

### 4. Configure the database and storage

```
# .env
DB_DATABASE=plateforme_annonces
MAIL_MAILER=log
```

```bash
mysql -u root -p -e "CREATE DATABASE plateforme_annonces CHARACTER SET utf8mb4;"
php artisan storage:link
php artisan notifications:table
```

### 5. Migrate and seed

```bash
php artisan migrate
```

Register the seeder in `DatabaseSeeder::run()`:
```php
$this->call([AnnoncesSeeder::class]);
```
```bash
php artisan db:seed
```

You get 6 categories, 5 users (Breeze factory default password: `password`), and 30 listings spread across them.
