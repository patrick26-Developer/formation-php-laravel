# Niveau 06 — Laravel Fondamentaux

> **Statut :** ✅ Disponible · Palier : Débutant Laravel

Après cinq niveaux de PHP pur, vous êtes prêt pour **Laravel**, le framework PHP le plus utilisé au monde. Chaque concept que vous découvrirez ici (routeur, MVC, ORM, validation) vous sera familier : vous l'avez déjà construit à la main aux niveaux 02 et 03. Ce niveau montre comment Laravel automatise et industrialise ce que vous savez déjà faire.

## Prérequis

[Niveau 05 — Outils professionnels](../05-outils-professionnels/README.md) complété (notamment Composer et Git).

## À la fin de ce niveau, vous saurez

- Installer et configurer un projet Laravel moderne.
- Définir des routes, des contrôleurs, et rendre des vues avec Blade.
- Manipuler une base de données avec Eloquent, sans écrire de SQL manuel.
- Versionner un schéma de base de données avec les migrations.
- Construire un CRUD complet avec tri, filtre, recherche et pagination, en une fraction du code nécessaire en PHP natif.
