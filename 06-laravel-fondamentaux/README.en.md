# Level 06 — Laravel Fundamentals

> **Status:** ✅ Available · Tier: Laravel Beginner

After five levels of pure PHP, you're ready for **Laravel**, the most widely used PHP framework in the world. Every concept you'll discover here (router, MVC, ORM, validation) will feel familiar: you've already built it by hand in levels 02 and 03. This level shows how Laravel automates and industrializes what you already know how to do.

## Prerequisites

[Level 05 — Professional Tools](../05-outils-professionnels/README.en.md) completed (notably Composer and Git).

## By the end of this level, you will be able to

- Install and configure a modern Laravel project.
- Define routes, controllers, and render views with Blade.
- Work with a database using Eloquent, without writing manual SQL.
- Version a database schema with migrations.
- Build a full CRUD with sorting, filtering, search, and pagination, in a fraction of the code needed in native PHP.
