# Running the Application

## Run the tests

```bash
php artisan test --filter=FeedTest
```

## Launch the application

```bash
php artisan serve
```

Log in with one of the accounts generated by the seeder (password `password`), then browse `/fil-actualite`: post, like, follow other accounts.

## Testing the API

```bash
curl -X POST http://localhost:8000/api/login -d '{"email":"...","password":"password"}' -H "Content-Type: application/json"
curl http://localhost:8000/api/v1/fil-actualite -H "Authorization: Bearer <token>"
```
*(Note: the `/api/login` endpoint is the one from the [level 09 mini-project](../../09-api-rest-laravel/projet-mini-06-api-rest-complete/README.en.md) — add it if starting from a blank project.)*

## Verifying the filtered news feed

Create three accounts A, B, C. A follows B but not C. Post from each. Logged in as A, `/fil-actualite` must show A's and B's posts, never C's — exactly what `FeedTest` verifies.
