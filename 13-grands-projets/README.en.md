# Level 13 — Complete Minimal Large Projects

> **Status:** ✅ Available · Tier: Portfolio

This level introduces no new concepts: it assembles **everything** learned since Level 00 into three complete, "portfolio"-sized applications — polished enough to present in a technical interview, deliberately scoped to their functional core ("minimal") rather than exhaustive.

## Large projects

| Project | Domain | Status |
|---|---|---|
| [Minimal e-commerce](grand-projet-02-ecommerce-minimal/README.en.md) | Catalog, cart, orders, simulated payment, admin | ✅ |
| [Minimal social network](grand-projet-03-reseau-social-minimal/README.en.md) | Posts, follow, likes, notifications, API | ✅ |
| [Multi-tenant billing SaaS](grand-projet-04-saas-facturation/README.en.md) | Multi-tenant, subscriptions, API, Docker, CI/CD | ✅ |

## Prerequisites

All of levels 00 through 12.

## How to approach this level

Each large project draws on modules from **several** different levels at once — each one's `JOURNAL.md` explicitly links back to every module involved. Unlike the mini-projects, it's not necessary (or even desirable) to work through these three projects in a strict order: pick the one whose domain speaks to you most, or all three if you want to cover e-commerce, social, and B2B SaaS.
