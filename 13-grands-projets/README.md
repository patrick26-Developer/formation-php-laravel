# Niveau 13 — Grands projets minimaux complets

> **Statut :** ✅ Disponible · Palier : Portfolio

Ce niveau ne présente pas de nouveaux concepts : il assemble **tout** ce qui a été appris depuis le Niveau 00 en trois applications complètes, de taille "portfolio" — suffisamment abouties pour être présentées en entretien technique, volontairement circonscrites à leur cœur fonctionnel ("minimales") plutôt qu'exhaustives.

## Grands projets

| Projet | Domaine | Statut |
|---|---|---|
| [E-commerce minimal](grand-projet-02-ecommerce-minimal/README.md) | Catalogue, panier, commandes, paiement simulé, admin | ✅ |
| [Réseau social minimal](grand-projet-03-reseau-social-minimal/README.md) | Publications, follow, likes, notifications, API | ✅ |
| [SaaS de facturation multi-tenant](grand-projet-04-saas-facturation/README.md) | Multi-tenant, abonnements, API, Docker, CI/CD | ✅ |

## Prérequis

L'intégralité des niveaux 00 à 12.

## Comment aborder ce niveau

Chaque grand projet mobilise des modules de **plusieurs** niveaux différents à la fois — le `JOURNAL.md` de chacun fait explicitement le lien vers chaque module concerné. Contrairement aux mini-projets, il n'est pas nécessaire (ni même souhaitable) de suivre ces trois projets dans un ordre strict : choisissez celui dont le domaine vous parle le plus, ou les trois si vous voulez couvrir e-commerce, social et SaaS B2B.
