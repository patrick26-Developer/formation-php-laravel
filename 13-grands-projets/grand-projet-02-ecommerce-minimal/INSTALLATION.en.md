# Installation

## Prerequisites

- PHP 8.3+, Composer, Node.js/npm, MySQL/MariaDB.
- Having completed at minimum levels 06, 07 and module 04.2 (transactions).

## Steps

### 1. Create the project with Breeze and Pest

```bash
composer create-project laravel/laravel ecommerce-minimal
cd ecommerce-minimal
composer require laravel/breeze --dev
php artisan breeze:install blade
npm install && npm run build
composer require pestphp/pest --dev --with-all-dependencies
php artisan pest:install
```

### 2. Add the relationship to the User model

Add the content of `app/Models/User-additions.php` into the `app/Models/User.php` generated by Breeze.

### 3. Copy this project's files

Copy `database/`, `app/` (Models, Contracts, Services, Exceptions, Policies, Http/Controllers), `resources/views/`, `tests/Feature/CheckoutTest.php`. Merge `routes/web.php` with Breeze's. **Replace** `app/Providers/AppServiceProvider.php`.

### 4. Database and seed

```
# .env
DB_DATABASE=ecommerce_minimal
```
```bash
mysql -u root -p -e "CREATE DATABASE ecommerce_minimal CHARACTER SET utf8mb4;"
php artisan migrate
```

Register `EcommerceSeeder` in `DatabaseSeeder::run()`, then:
```bash
php artisan db:seed
```

### 5. Create an admin account

```bash
php artisan tinker
>>> \App\Models\User::first()->update(['est_admin' => true]);
```
