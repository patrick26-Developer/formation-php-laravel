# 🐘 PHP → Laravel — La Formation Complète

> De zéro à expert : PHP moderne, Laravel, bases de données, API REST, fullstack, Docker et CI/CD — gratuitement, pour tout le monde.

**🇫🇷 Français** (langue source, toujours la plus à jour) · 🇬🇧 [English](README.en.md) *(traduction en cours de construction, module par module)*

---

## 🎯 Pour qui ?

Ce dépôt est une formation **complète, gratuite et progressive** pour apprendre PHP depuis les bases absolues jusqu'à la maîtrise experte de **Laravel**, le framework PHP le plus utilisé au monde. Elle s'adresse à :

- Des **débutants complets** en programmation qui veulent un parcours structuré et sans trou.
- Des développeurs d'autres langages qui veulent devenir productifs en PHP/Laravel rapidement.
- Des développeurs PHP intermédiaires qui veulent combler leurs lacunes (sécurité, tests, architecture, DevOps).
- Des développeurs qui préparent des entretiens techniques ou veulent industrialiser leurs pratiques (Docker, CI/CD).

## 🗺️ Comment naviguer

Le point d'entrée pédagogique est le **[SOMMAIRE.md](SOMMAIRE.md)** : la table des matières complète de la formation, niveau par niveau, avec le statut d'avancement de chaque module (✅ disponible, 🚧 en cours, 📋 planifié).

La formation est organisée en **15 niveaux numérotés** (`00-introduction` → `14-preparation-professionnelle`), à suivre dans l'ordre la première fois. Chaque niveau est un dossier contenant des **modules** numérotés, et chaque module contient :

- `README.md` — le cours (théorie + exemples de code commentés)
- `EXERCICES.md` — des exercices pour pratiquer
- `solutions/` — les corrigés commentés
- éventuellement du code exécutable (`code/`)

Les **mini-projets** et **grands projets** sont des dossiers à part, rattachés au niveau qui les rend possibles. Chacun contient un **kit documentaire standard** — voir [CONTRIBUTING.md](CONTRIBUTING.md#kit-documentaire-dun-projet) pour le détail du rôle de chaque fichier (installation, exécution, journal de construction, ressources).

## 🚀 Par où commencer ?

1. Lisez [00-introduction/01-presentation-parcours](00-introduction/01-presentation-parcours/README.md) pour comprendre la philosophie du parcours.
2. Installez votre environnement avec [00-introduction/02-installation-environnement](00-introduction/02-installation-environnement/README.md).
3. Suivez les niveaux dans l'ordre, faites **tous les exercices**, construisez **tous les mini-projets**.
4. Consultez [ressources/](ressources/) à tout moment pour les cheatsheets et la FAQ.

## 🛠️ Stack de référence de la formation

- **PHP** 8.3+ (syntaxe moderne : types stricts, enums, readonly, match...)
- **Laravel** (dernière version stable)
- **Fullstack** : Blade + **Livewire** (100% PHP, sans framework JS lourd)
- **Base de données** : MySQL / MariaDB
- **Tests** : PHPUnit (fondations) puis **Pest** (Laravel)
- **DevOps** : Docker, Docker Compose, GitHub Actions
