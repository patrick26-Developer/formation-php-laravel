# Level 05 — Professional Tools

> **Status:** ✅ Available · Tier: Cross-cutting

This level equips you with the tools every professional developer uses daily: a real team Git workflow, Docker for reproducible environments, GitHub Actions for continuous integration, and code quality analysis tools. These skills are cross-cutting: they apply just as much to native PHP as to Laravel.

## Prerequisites

[Level 03 — Advanced PHP](../03-php-avance/README.en.md), notably [03.3 — Unit Testing with PHPUnit](../03-php-avance/03-tests-unitaires-phpunit/README.en.md).

## By the end of this level, you will be able to

- Work with a real team Git workflow: branches, merge/rebase, pull requests.
- Containerize a PHP application with Docker and orchestrate several services with Docker Compose.
- Set up a CI pipeline that automatically tests your code on every `push`.
- Automate static analysis and formatting of your code.
