# Niveau 05 — Outils professionnels

> **Statut :** ✅ Disponible · Palier : Transversal

Ce niveau vous équipe des outils que tout développeur professionnel utilise au quotidien : un vrai workflow Git d'équipe, Docker pour des environnements reproductibles, GitHub Actions pour l'intégration continue, et des outils d'analyse de qualité de code. Ces compétences sont transversales : elles s'appliquent aussi bien au PHP natif qu'à Laravel.

## Prérequis

[Niveau 03 — PHP Avancé](../03-php-avance/README.md), notamment [03.3 — Tests unitaires avec PHPUnit](../03-php-avance/03-tests-unitaires-phpunit/README.md).

## À la fin de ce niveau, vous saurez

- Travailler avec un vrai workflow Git en équipe : branches, merge/rebase, pull requests.
- Containeriser une application PHP avec Docker et orchestrer plusieurs services avec Docker Compose.
- Mettre en place un pipeline CI qui teste automatiquement votre code à chaque `push`.
- Automatiser l'analyse statique et le formatage de votre code.
